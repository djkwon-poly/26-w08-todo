## 소개

Tailwind CSS와 순수 JavaScript로 만든 브라우저 기반 투두리스트입니다. 별도의 가입이나 서버 없이 할 일을 등록하고, 일정과 우선순위에 따라 관리할 수 있습니다. 데이터는 현재 브라우저의 `localStorage`에 저장됩니다.

주요 기능:

- 할 일 추가, 수정, 삭제 및 완료/미완료 전환
- 제목, 설명, 카테고리, 우선순위, 시작 일시와 마감 일시 관리
- 전체·오늘 할 일·완료 목록 필터와 생성순·마감일순·우선순위순 정렬
- 전체 진행률과 탭별 할 일 개수 표시
- 모바일과 데스크톱 화면 지원

## 어떻게 만들었나요

PRD의 기능·데이터·예외 처리 기준을 바탕으로 구현했습니다. 화면은 Tailwind CSS Play CDN과 보조 CSS로 반응형 구성했고, 할 일 상태·이벤트 처리·저장소 동기화는 Vanilla JavaScript로 작성했습니다. 별도의 JavaScript 라이브러리나 빌드 도구는 사용하지 않습니다.

## Bootstrap vs Tailwind

Bootstrap은 미리 정의된 컴포넌트와 일관된 기본 스타일을 빠르게 적용하기 좋습니다. Tailwind는 간격·색상·레이아웃 등의 유틸리티 클래스를 HTML 요소에 조합해 화면을 세밀하게 조정할 수 있습니다.

이 버전은 Tailwind를 선택했습니다. 반응형 레이아웃과 앱의 색상·간격을 요소별로 조정하기 편하고, HTML에서 스타일 적용 위치를 바로 확인할 수 있기 때문입니다. Bootstrap의 `btn btn-primary` 같은 컴포넌트 클래스 대신 Tailwind의 `rounded-xl bg-indigo-600 px-4 py-2`와 같은 유틸리티 클래스를 조합합니다.

## 실행 방법

### 로컬에서 실행

1. 저장소를 내려받거나 Codespaces에서 엽니다.
2. `index.html`을 브라우저에서 엽니다. 정적 파일 서버를 사용하는 경우 저장소 루트에서 실행하면 됩니다.
3. Tailwind CSS CDN을 불러오려면 인터넷 연결이 필요합니다.

할 일 데이터는 브라우저의 `localStorage`에 저장됩니다. 브라우저별로 데이터가 분리되며, 브라우저 저장 데이터를 지우면 등록한 할 일도 삭제됩니다.

### GitHub Pages 배포

GitHub 저장소의 **Settings → Pages**에서 배포 브랜치와 저장소 루트(`/`)를 지정하면 정적 페이지로 배포할 수 있습니다. 배포가 완료되면 아래에 실제 주소를 적어 공유하세요.

- 배포 주소: 아직 설정되지 않음

Tailwind Play CDN은 개발·학습용입니다. 실제 운영 서비스로 배포할 때는 Tailwind CLI 등으로 CSS를 빌드하는 방식을 권장합니다.

## 커스터마이징한 부분

마감 일시는 상세 설정을 열지 않아도 입력할 수 있도록 기본 폼에서 강조했습니다. 시작 일시는 상세 영역에서 선택 입력할 수 있고, 시작 시각이 마감 시각보다 늦으면 저장되지 않습니다. 일정 기간이 오늘과 겹치는 할 일은 ‘오늘 할 일’에 표시합니다.

삭제 전에는 금빛 모자이크풍 아이콘과 할 일 제목이 있는 앱 내 확인 팝업을 표시합니다. 할 일을 완료하면 체크박스 주변에 꽃가루 애니메이션이 나타나며, 운영체제의 동작 줄이기 설정을 존중합니다. 사용자 입력은 HTML로 해석하지 않고 텍스트로 표시하며, 저장소 오류가 발생하면 화면에 안내합니다. 모바일 화면에서는 필터 탭을 가로로 스크롤할 수 있습니다.
