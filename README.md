# ✅ To-Do 리스트

> 작성일: 2026년 10월 26일

> 이 README는 실습을 완성한 뒤, 배포 직전 단계에서 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 소개

Tailwind CSS CDN과 Vanilla JavaScript로 만든 브라우저 기반 투두리스트입니다. 할 일 추가·수정·삭제, 시작·마감 일시 관리, 완료 상태 관리, 오늘/완료 필터, 정렬 및 진행률 확인을 지원합니다. 데이터는 브라우저의 `localStorage`에 저장됩니다.

## 어떻게 만들었나요

PRD를 바탕으로 Tailwind CSS Play CDN을 사용해 반응형 UI를 구성하고, 별도의 JavaScript 프레임워크 없이 상태와 동작을 구현했습니다.

## Bootstrap vs Tailwind

이 브랜치는 Tailwind CSS 버전입니다. Bootstrap 버전과 화면 및 HTML 유틸리티 클래스 구성을 비교한 뒤 선택 결과를 기록하세요.

## 실행 방법

`index.html`을 브라우저에서 열어 실행합니다. Tailwind CSS Play CDN을 불러오려면 인터넷 연결이 필요합니다. 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. Play CDN은 개발·학습 용도이며, 운영 배포에는 빌드된 CSS 사용을 권장합니다.

## 커스터마이징한 부분

마감 일시를 상세 설정을 열지 않아도 입력할 수 있도록 기본 폼에서 강조했습니다. 일정 기간이 오늘과 겹치는 할 일은 ‘오늘 할 일’에 표시하며, 시작 일시와 마감 일시의 순서를 검증합니다. 모바일에서는 필터 탭을 가로로 스크롤할 수 있고, 입력 글자 수와 필터별 항목 수도 표시합니다.
